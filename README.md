CV Field Services — Hand‑Built HTML/CSS Website

This repository contains a fully hand‑coded static website built for CV Field Services, a property inspection service provider. The project demonstrates front‑end development fundamentals, structured file architecture, version control practices, and modern deployment workflows. All pages are written in semantic HTML and styled with a custom CSS stylesheet, organized into a clean asset directory.

The goal of this project is to showcase practical IT skills through a real‑world deliverable: a multi‑page website built from scratch, deployed through a cloud hosting platform, and connected to a custom domain. This project reflects an understanding of web structure, hosting, DNS configuration, and code organization.

Purpose  
This project is part of a professional IT portfolio and demonstrates the ability to build, structure, and deploy a website manually without relying on visual builders or templates. It highlights technical competency, attention to detail, and an understanding of modern web deployment practices.
